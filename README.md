# 💈 Acer Cuts - Premium Barbing Booking System

Live Demo: https://acer-cuts.onrender.com

## Features
- ✅ Book Appointment - Customers can book with name, phone, date
- ✅ Styles Gallery - View all haircuts with prices
- ✅ Admin Dashboard - See all bookings
- ✅ Mobile Responsive - Works on phone

## Tech Stack
- Laravel 11
- Tailwind CSS
- MySQL (Render)
- Render Hosting
